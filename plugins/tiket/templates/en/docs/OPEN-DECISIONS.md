# Open decisions

A list of things the product owner has not decided yet. Agents must not fill in these values themselves.

When a ticket needs one of these decisions:
- use its example value in seeds and tests, with the marker `{{EXAMPLE_MARKER}}`;
- name its OD ID in the PR.

After the owner decides through `/tiket:catat-keputusan`, the decision is written into `docs/PRD.md` as a ▶ Decision block, and its row is removed from this table.

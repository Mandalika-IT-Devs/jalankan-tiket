# Input material

Put raw material about the product in this folder, for example:
- notes;
- documents from ChatGPT or from meetings;
- sample files, screenshots and spreadsheets.

`/tiket:rencanakan-produk` reads this material to write the PRD, the glossary and the open decisions.

The files in this folder are not rules. Only what is already in `docs/PRD.md` applies. Do not put real personal data here.

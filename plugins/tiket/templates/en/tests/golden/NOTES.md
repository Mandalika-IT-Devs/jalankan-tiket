# Golden fixtures

This folder holds correct calculation examples, taken from the PRD.

This folder is read-only. Agents must not change it, because it is one of the protected files. When a test is red, fix the code, not the fixtures here.

Each PRD rule has one JSON file, for example `late-fee.json`. It holds cases with the input, the expected output and a reference to the PRD §.

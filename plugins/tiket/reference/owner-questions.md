# Questions for the owner

This format applies to every question that needs the owner:
- parked tickets;
- non-blocking questions in a final report;
- open decisions raised while planning.

Write each question in the project language, in plain words. Use that one language for the whole message: never give the same text twice in two languages.

## Each question carries

- **Answer options.** Exactly one option is marked as the recommendation, chosen by best practice. Write the marker in the project language: `(rekomendasi)` or `(recommended)`.
- **One sentence of reason** for the recommendation.
- **The cost of changing course later.** Use the project language: `kecil`/`sedang`/`besar` or `small`/`medium`/`large`.

Number the questions. End the list with this line in the project language:
- Indonesian: "Jawab 'setuju semua' atau sebut nomor yang berbeda."
- English: "Answer 'agree to all' or name the numbers that differ."

## Example (Indonesian project)

```
1. Berapa buku yang boleh dipinjam satu anggota sekaligus?
   - a) 2 buku
   - b) 3 buku (rekomendasi)
   - c) 5 buku
   Alasan: 3 buku cukup untuk kebanyakan anggota dan menjaga koleksi tetap beredar.
   Biaya ubah: kecil.

Jawab 'setuju semua' atau sebut nomor yang berbeda.
```

`/tiket:catat-keputusan` records the owner's answers.
